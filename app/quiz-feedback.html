Q1 객관식
파이썬 리스트에서 마지막 원소를 제거하고 반환하는 메서드는?
정답
✓ 정답: C) pop()
list.pop()은 마지막 원소를 제거하고 반환합니다. pop(index)로 특정 위치도 제거 가능합니다.
Q2 객관식
딕셔너리에서 존재하지 않는 키에 접근 시 기본값을 반환하는 메서드는?
오답
✗ 내 답: A) dict.find(key) · ✓ 정답: B) dict.get(key, default)
dict.get(key, default)는 키가 없을 때 KeyError 대신 지정한 기본값을 반환합니다. find()는 딕셔너리 메서드가 아닙니다.
Q3 객관식
리스트 컴프리헨션의 올바른 사용법은?
정답
✓ 정답: B) [x*2 for x in range(5)]
리스트 컴프리헨션은 대괄호 [ ]를 사용합니다. { }는 집합/딕셔너리, ( )는 제너레이터입니다.
Q4 단답형
딕셔너리에서 모든 키를 반환하는 메서드를 작성하세요.
오답
✗ 내 답: dict.keys · ✓ 정답: dict.keys()
dict.keys()처럼 반드시 괄호를 붙여야 메서드가 호출됩니다. 괄호 없이 dict.keys는 메서드 객체 자체를 참조합니다.
Q5 코드 완성
빈칸을 채워 1~10의 짝수 리스트를 만드세요.
정답
✓ 정답: if x % 2 == 0
x % 2 == 0은 x가 짝수임을 의미합니다. 리스트 컴프리헨션의 조건절로 사용하면 짝수만 필터링됩니다.
Q6 객관식
튜플(tuple)과 리스트(list)의 가장 큰 차이점은?
정답
✓ 정답: B) 튜플은 변경 불가(immutable)이다
튜플은 한 번 생성되면 요소를 추가·수정·삭제할 수 없는 불변(immutable) 자료구조입니다. 리스트는 가변(mutable)입니다.
Q7 객관식
딕셔너리의 update() 메서드의 역할은?
정답
✓ 정답: A) 다른 딕셔너리의 키-값 쌍을 추가/수정한다
dict.update(other)는 other 딕셔너리의 내용을 현재 딕셔너리에 병합합니다. 기존 키가 있으면 덮어씁니다.
Q8 단답형
리스트에서 특정 값의 인덱스를 반환하는 메서드는?
오답
✗ 내 답: find() · ✓ 정답: index()
list.index(value)는 리스트에서 해당 값의 첫 번째 인덱스를 반환합니다. find()는 문자열(str)의 메서드입니다.
Q9 객관식
리스트 슬라이싱 a[1:4]의 결과로 맞는 것은? (a = [0,1,2,3,4])
정답
✓ 정답: C) [1, 2, 3]
슬라이싱 a[start:end]는 start 인덱스부터 end-1 인덱스까지 반환합니다. a[1:4]는 인덱스 1, 2, 3에 해당하는 [1, 2, 3]을 반환합니다.
Q10 객관식
딕셔너리에서 키-값 쌍을 순회할 때 사용하는 메서드는?
정답
✓ 정답: B) .items()
dict.items()는 (key, value) 튜플 쌍을 반환합니다. for k, v in d.items() 패턴으로 자주 사용됩니다.
